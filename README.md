# 苗栗政策島｜2026 苗栗縣長候選人政見對照

**線上看：** https://mattsue1003.github.io/miaoli-policy-island/

把 2026 苗栗縣長兩位候選人——陳品安（民主進步黨）、鍾東錦（中國國民黨，現任）——的政見做成兩座 3D 小島。一格六邊形是一項政策主題，點開可看細項、出處原文與可行性檢核；另有議題對照表與 8 個爭點的成本試算。

> 本站**不是**任何候選人或政黨的官方網站。內容整理自新聞報導與候選人公開發言（截至 2026-10-27），中選會選舉公報尚未發布；以公報為準。

## 內容與方法

- **政見細項**：每項附來源與原文摘錄；來源連結使用文字片段定位（`#:~:text=`），點開會捲到並標亮引用段落（Chrome／Edge／Safari 支援）。2026-10-26 全面事實查核，修正紀錄見 [`changelog_factcheck.md`](changelog_factcheck.md)。
- **具體度檢核（不評好壞）**：金額、時程、財源、縣府權責四項。
- **公平原則**：現任者的「施政紀錄」與新承諾分開，不列入具體度；「執行進度」只作現況資訊，因為非現任者沒有執行權。議題對照表預設只比新承諾。
- **爭點分析**：雙方說法、成本試算（附公式與每個數字的出處）、卡關點、其他縣市做法、可追問的問題。查不到的數字標「資料不足」，不自行推估。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 網站本體（單一檔案，three.js 由 jsDelivr 載入） |
| `data.json` | 候選人、政見細項、出處、引文、議題分組 |
| `feasibility.json` | 每項政見的檢核結果與依據 |
| `issues_deep.json` | 爭點深入分析 |
| `src/` | 產生 `index.html` 的模板與 3D 場景原始碼 |

## 重新產生

```bash
cd src
python3 build.py ../data.json   # 產生 src/index.html（不含 doctype 的嵌入版）
```
